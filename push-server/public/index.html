SCInsta Notifier

Puente Calm Tech de notificaciones directas para iOS.

  • 1. Compartir > Agregar a pantalla de inicio En Safari iOS, toca el botón Compartir y añade esta Web App a tu pantalla de inicio antes de continuar.
  • 2. Activar notificaciones Abre la app instalada desde tu pantalla de inicio y pulsa el botón inferior para vincular Web Push.
